# Sourcing Monitor status filter

The overview toolbar includes a multi-select Search status filter. It supports Open, Closed, Abandoned, Cancelled, Placed and additional statuses present in the workspace. All statuses are included initially; Clear filter restores all. Statuses combine with search selection, text, team and attention filters. The Searches dropdown shows only searches in the selected statuses. The existing monitor navigation state retains status selections across drill-down and return.

Verification: typecheck, the full automated suite and production build gate deployment. No stored search status, history, permissions or metrics definitions change.
