# Candidate engagement panel layout

Use a fixed header and one scrolling body. Group company/search context, stage, next action and assignees into compact labelled facts. Use a smaller attention notice and a separate actions row. Activity entries show type, readable date, stage transition, optional notes and author; do not repeat the already-selected candidate name and LinkedIn icon on every entry. Empty notes no longer create blank paragraphs.

Verification: typecheck, full test suite and production build gate this release. The owner screenshot informed the layout; signed-in visual verification was unavailable. No engagement data or permission changes.
