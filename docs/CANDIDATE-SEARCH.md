# Candidate filtering and query interpretation — October 4, 2026

Column filters treat the first choice as an inclusion, not an exclusion from an implicitly checked master list. Typing searches available options without silently changing selected values. Enter selects a single matching option; Use matching values applies visible matches. Clear filter restores unrestricted results. Selected labels are visible.

Company filters match case/spacing/punctuation-normalized names, linked master aliases and mapping history. No fuzzy spelling guesses. Candidate text queries search the existing profile/notes/evidence/search-history index plus visible fields and tags. A deterministic parser recognizes country/locality names and compensation above/below limits with explicit USD, GBP or INR amounts and k/million/lakh/crore units. Other words remain text terms. This is a bounded parser, not general-purpose AI language understanding. The interpreted query is displayed. Unknown, wrong-currency and overlapping compensation bands are excluded; free-form compensation details remain searchable text, not authoritative numeric values. Existing column filters are combined with query constraints.

Verification: typecheck and 246 synthetic tests passed; production build passed. Coverage includes first-click/multi-selection behavior, and/& matching, company spacing/aliases/history, exact absent tags, geography hierarchy, explicit million amounts, mixed-unit compensation bands, unknown/overlapping/wrong-currency exclusion and keyword tag search without a cached index. Live verification is recorded separately after deployment. No candidate records were changed.
