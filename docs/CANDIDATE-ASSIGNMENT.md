# Candidate-to-search assignment

Assign selected candidates requires only a destination search. Single and bulk selection use the same preview/confirm flow. The server links existing candidates as Draft mappings with no team or target-company allocation and records the initiating researcher. Duplicate mappings are skipped; stale previews and invalid candidates remain transactional failures. The optional search link during Excel import behaves the same way. Existing Researcher permission remains required for mapping, and Excel import remains restricted to Data quality analyst / Super admin.

Research team allocation remains in Weekly plan. For directory links without a stored team, team-review eligibility follows the teams on the latest effective (not future) sourcing allocation date for that search and their current membership. A later allocation replaces earlier team eligibility; searches without allocations retain search-partner and super-admin review access. Existing mappings with recorded teams retain their team scope. Formal partner review remains separate. Merely linking candidates does not create assignments or completed output.
