# Internal navigation and funnel assignments

App-wide in-app Back/Forward records up to 50 page transitions, including candidate profile transitions. Navigation is scoped to the signed-in workspace/account, cleared on reset, and guarded for unsaved edits. Delivery Monitor preserves its view, search filters, query, status, dates, team, attention and sort. View mapping opens the selected mapping with a direct return button. This adds internal controls; it does not modify native browser history or promise persistence across reloads.

Engagement Assignments now supports group_member_ids per search, with member_ids retained as the derived union. Legacy search-wide assignments apply across all groups until explicitly saved by funnel. Server and UI authorize members against the candidate's current funnel; movement can hand off to a different funnel. Work Queue filters member work by current funnel. Interview Tracker follows the same authorization. Search partner and existing planning/admin privileges remain search-wide. Server validates groups, active Engagement members, closed-search rules and optimistic versions; saves retain event/audit history. No individual candidate ownership is added.
